✈️ Flight Management System (Java)

 📌 Description

The **Flight Management System** is a Java-based application designed to manage airline operations efficiently. It allows users to add flights, register passengers, search and sort flight schedules, and store data permanently using file handling. The project is built using Object-Oriented Programming (OOP) principles and Data Structures, making it ideal for academic and learning purposes.

 🚀 Features

* Add new flights
* Register passengers to flights
* View complete flight schedule
* Search flights by flight number
* Sort flights alphabetically
* Save data to a text file
* Load saved data automatically on startup
* User-friendly Java Swing GUI
* 
 🛠️ Technologies Used

* Java
* Java Swing (GUI)
* File Handling (BufferedReader / BufferedWriter)
* Data Structures (Linked Lists, Arrays)

 🧠 Concepts Covered

* Object-Oriented Programming (Classes, Objects, Encapsulation)
* Doubly Linked List (Flights)
* Singly Linked List (Passengers)
* Binary Search
* Insertion Sort Algorithm
* File Input/Output

📁 Project Structure

Main.java          // GUI and main application
Airline.java       // Flight management and sorting logic
Flight.java        // Flight and passenger handling
Passenger.java     // Passenger node structure
FileManager.java   // Save and load data from file
flights.txt        // Data storage file

 ▶️ How to Run the Project

1. Clone or download the repository
2. Open the project in any Java IDE (IntelliJ, Eclipse, NetBeans)
3. Compile all `.java` files
4. Run `Main.java`
5. Use the GUI buttons to manage flights and passengers

💾 Data Storage

* All flight and passenger data is saved in `flights.txt`
* Data is automatically loaded when the application starts
